# 사주며려 (saju-me-ryeo)

생년월일시를 바탕으로 사주 명식을 살펴보는 웹 서비스입니다.

## 소개

**사주며려**는 사용자의 출생 정보를 입력받아 사주팔자를 계산·정리하고, 결과를 웹에서 쉽게 확인할 수 있도록 만드는 프로젝트입니다.

## 주요 기능 (예정)

- 생년월일시·성별 기반 사주 명식 계산
- 사주팔자·오행 등 핵심 정보 시각화
- 모바일·데스크톱 대응 웹 UI

## 시작하기

프로젝트 설정과 실행 방법은 개발이 진행되면 이곳에 추가됩니다.

```bash
git clone https://github.com/shookcream/saju-me-ryeo.git
cd saju-me-ryeo
```
